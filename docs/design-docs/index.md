# Design Docs

This directory holds durable engineering design guidance. It is the first stop
when a change affects project rules, command harness behavior, code unit shape,
or other implementation conventions.

## Source Of Truth

- [agent-workflow.md](agent-workflow.md): canonical agent planning,
  implementation approval, checked-in execution plans, validation, review, and
  commit workflow.
- [project-invariants.md](project-invariants.md): repo-wide invariants and the
  doc-first workflow.
- [harness.md](harness.md): local setup, command harness, and validation flows.
- [code-unit-design.md](code-unit-design.md): code unit boundaries, interfaces,
  and testing expectations.
